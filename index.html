Getting Started

Up and running in 60 seconds

No installation wizard, no dependencies. Download, run, draw.

1

Download

Click the download button for your OS above. Pick the latest release for your platform.

2

Run — Windows

Double-click the .exe file. That's it — no install, no setup wizard, no admin rights needed.

2

Run — Linux

Make the AppImage executable and run it. Two commands in a terminal, and you're done.

3

Start Drawing

The editor opens with a blank canvas and a sample character. Pick a tool on the right, pick a color, and paint.

Tools

Every tool you need. Nothing you don't.

Eleven focused tools — each one designed for pixel-perfect work.

Brush

Paint pixels with 4 effects: Normal, Spray, Glow, and Texture. Size 1–16px.

Eraser

Erase pixels back to transparent. Right-click with any tool to erase temporarily.

Fill / Bucket

Flood-fill connected pixels of a similar color. Tolerance slider controls how picky it is.

Magic Wand

Click a color to erase all connected pixels of that color. Fast cleanup.

Color Picker

Click any pixel to grab its color as your active color.

Rectangle Select

Drag to select a rectangular area. Paint tools stay inside that box.

Ellipse Select

Same as Rectangle, but selects an ellipse. Great for circular sprites.

Lasso Select

Click points to draw a custom selection polygon. Click near the first point to close.

Path Brush

Place points, right-click to apply. 12 styles: smooth, dotted, dashed, zigzag, wavy, ribbon, and more.

Move

Move the whole frame with the arrow keys. Shift+arrow moves 8 pixels at once.

Mask

Paint a free-form mask, then press R / G / S to transform only the masked area. Switching tools clears it automatically.

Text

Stamp uppercase letters and numbers using a built-in 5×7 pixel font.

Blender-style Transforms

Rotate. Grab. Scale. Chain them freely.

Select an area, then press R, G, or S. Move your mouse to transform. Left-click to apply, right-click or Esc to cancel. Switch between transforms at any time — they stack.

R

Rotate

Spin the selection around its center

  • Angles snap to 45° increments
  • Axis is fixed at the center of your selection
  • Press G afterward to move the rotated result
G

Grab

Move the selection freely

  • Pixels keep their original color
  • Pixels outside the canvas are preserved until you commit
  • Cancel and restore at any time with Esc
S

Scale

Shrink or expand from the center

  • Move mouse away from center to grow
  • Move mouse toward center to shrink
  • Nearest-neighbor keeps pixel edges crisp
R → G → S → ✓ Apply Chain any combination — each step commits silently and the next one starts from there.

About

Built by a game dev, for game devs.

No accounts. No cloud sync. No subscription. Just a fast, focused tool that runs on Windows and Linux and works entirely offline.
